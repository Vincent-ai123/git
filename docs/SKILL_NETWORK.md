<a id="programming-basics"></a>

### 程序设计基础

**位置：** C++ 与计算机基础 → 程序设计与抽象 → 程序设计基础

**知识分类：** 工具与基础 / 编程基础

理解变量、类型、控制流、函数、数据表示与程序状态。

**为什么学：** 语言可以更换，分解问题和追踪程序行为的能力可以复用。

**具体知识点**

- 变量、类型与值
- 条件、循环与控制流
- 函数、参数与作用域
- 输入校验与错误处理
- 程序状态与问题分解

**前置：** 起点节点，可从基础概念开始。

**后续用途：** 计算机组成与体系结构、C 语言与内存基础、测试设计、数据结构、面向对象与接口设计、现代 C++、Python、Java、Go、计算机网络、并发与同步、数据质量与治理、大语言模型基础

**关联岗位（含前置复用）：** C++ 系统与量化开发、金融科技后端、通用后端与数据平台、AI 应用 / Agent / RAG、量化研究、AI 基础设施 / GPU 系统

**验证成果：** 把一个需求拆成函数，处理输入边界，并手工追踪一段程序的状态变化。

<a id="discrete-math"></a>

### 离散数学与逻辑

**位置：** C++ 与计算机基础 → 数据结构与算法 → 离散数学与逻辑

**知识分类：** 工具与基础 / 数学

理解集合、逻辑、关系、图、组合计数和基本证明方法。

**为什么学：** 算法正确性、数据建模和系统状态都依赖明确的离散结构。

**具体知识点**

- 命题逻辑与集合
- 关系、函数与图
- 排列组合与计数
- 归纳法与循环不变量
- 反例与边界证明

**前置：** 起点节点，可从基础概念开始。

**后续用途：** 算法与复杂度

**关联岗位（含前置复用）：** C++ 系统与量化开发、通用后端与数据平台

**验证成果：** 用不变量解释一个算法为何正确，并给出一个边界反例。

<a id="computer-architecture"></a>

### 计算机组成与体系结构

**位置：** C++ 与计算机基础 → 计算机组成与体系结构 → 计算机组成与体系结构

**知识分类：** 工具与基础 / 计算机基础

理解指令执行、CPU、缓存、内存层次、数据表示与 I/O。

**为什么学：** 系统性能、内存错误和软硬件协作需要共同的机制解释。

**具体知识点**

- 二进制、补码与浮点表示
- 指令、流水线与分支
- 寄存器、缓存与主存
- 局部性、缓存行与伪共享
- 中断、DMA 与 I/O

**前置：** 程序设计基础

**后续用途：** 操作系统、GPU 并行与内存层次

**关联岗位（含前置复用）：** C++ 系统与量化开发、通用后端与数据平台、AI 基础设施 / GPU 系统

**验证成果：** 用缓存局部性或数据布局解释两段等价程序的性能差异。

<a id="calculus"></a>

### 微积分与优化基础
