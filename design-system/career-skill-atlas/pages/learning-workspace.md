# Learning workspace · v1.3.0

本页覆盖 MASTER.md 中旧版的深色配色与远程字体方案。依据用户对可读性和交互的反馈，使用固定位置的二维分层地图。

## 视觉规则

| 用途 | 颜色 |
|---|---|
| 页面背景 | `#f6f7f2` |
| 正文 | `#22392f` |
| 主操作与依赖高亮 | `#245b47` |
| 次要文字 | `#5b6b62` |
| 节点与操作表面 | `#ffffff` |
| 辅助面板 | `#edf2e8` |

使用本机 Segoe UI / 微软雅黑；标题与正文使用同一字体族，通过字号与字重建立层次。首页用真实学习主线作为视觉中心，不添加装饰性球体。内容左对齐；节点、说明、操作区域分别以边框、间距和浅色底区分。

## 交互规则

- 一次只显示概念、模块、技能、内容中的一层；保留面包屑与浏览器返回。
- 节点位置固定；依赖默认淡化，悬停或键盘聚焦时高亮。跨列或跨行连线绕开其他节点。
- 鼠标可拖动，键盘与按钮可缩放复位；手机优先显示清单，地图放大后可滑动查看。
- 文字标签、学习状态与完成符号不依赖颜色；焦点可见，尊重减少动画设置。
- 不新增外部运行依赖；保留全部知识内容、路线与浏览器进度。

设计辅助：find-skills 搜索发现的 Anthropic frontend-design，以及本机 UI/UX Pro Max；最终选择以本项目的阅读与学习需求为准。
