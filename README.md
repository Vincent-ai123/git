# Career Skill Atlas · 个人计算机知识地图

[打开交互网站](https://vincent-ai123.github.io/git/) · [六个方向的岗位拆解](docs/ROLE_REQUIREMENTS.md) · [分层知识点与依赖网络](docs/SKILL_NETWORK.md) · [官方 JD 样例](docs/JD_EVIDENCE.md)

根据《2026-10-17_学习路线与资源清单》和《2026-10-17_分阶段学习路线》，把共同工程底座、项目验证和岗位分支组织成可以逐层展开的个人知识体系。

当前版本 **1.2.0（2026-10-19）**：**6 个岗位方向、8 个大概念、30 个模块、69 个技能、345 项具体学习内容、122 条前置关系、12 份官方 JD 样例**。网站与生成文档共用 `data.js`。

## 怎样浏览

知识地图从 **8 个大概念**开始，点击后依次进入 **模块 → 技能 → 具体学习内容**。例如：

> 交易系统与量化研究 → 订单簿与回放项目 → 订单簿 → 价格优先、时间优先与数量守恒等具体内容。

- **3D 球状图谱**：透视球面、自动旋转、拖动旋转、方向按钮、缩放和复位；标签自动避让，并用引线连接球面节点。悬停、键盘聚焦或系统开启减少动画时停止自动旋转；页面不可见时停止绘制。
- **逐层返回**：面包屑、返回上层和浏览器前进/后退；地址保存岗位和当前概念、模块、技能，可收藏分享。
- **分层清单**：与球体显示同一层的节点。手机初次打开默认使用清单，也可切换球体；触屏横向拖动旋转、纵向滚动页面。
- **技能详情**：学习范围、为什么学、具体内容、前置关系、后续用途、关联岗位和可验证成果。前置链也按概念分组展开，保持每屏内容有限。
- **按需搜索**：完整技能索引默认收起，搜索时打开。按 `/` 聚焦搜索。
- **学习路径与进度**：为岗位排列先修基础、核心技能、项目验证和进阶分支；支持 12 种技术栈组合。进度保存在当前浏览器，可导出 JSON、跨设备导入合并，继续兼容旧版进度键。

## 六个岗位方向

| 岗位方向 | 当前定位 | 作品重点 |
|---|---|---|
| C++ 系统与量化开发 | 主修 | 行情回放、订单簿、测试与性能证据 |
| 金融科技后端 | 主修第二方向 | API、数据库、鉴权、幂等和消息可靠性 |
| 通用后端与数据平台 | 主修第二方向 | 可部署服务或可复现数据管道 |
| AI 应用 / Agent / RAG | 主修第二方向 | 金融资料检索助手、引用、工具调用与评测 |
| 量化研究 | 长期补充 | 样本外验证、交易成本和研究报告 |
| AI 基础设施 / GPU 系统 | 完成主线后的选修探索 | CPU / PyTorch / CUDA 或 Triton 的正确性与性能对照 |

共同主线是：**现代 C++ → Linux / 操作系统 / 网络 → SQL / 数据库 → C++ 行情回放与订单簿 → Python / 统计 / 机器学习 → 后端或 Agent / RAG 应用**。研究与 GPU 分支按目标选择，不必同时推进所有方向。

前端、移动端、安全、嵌入式等不再作为独立岗位入口；数据库、部署、安全基础等仍作为相关方向需要的技能保留。岗位画像是通用准备建议，各份 JD 的明示要求独立列出。

## 招聘证据

12 份样例来自 Databricks、Stripe、Cloudflare、Datadog、NVIDIA、Jane Street 的官方招聘系统，主要来自海外与香港，包含相邻研究岗位及方向汇总。它们用于理解要求，不能推算中国市场热度或统一学历门槛。

每份记录保留原文链接、公开数据源、资格、职责、加分项、短摘与核查日期。来源可读取不代表仍可投递；请复核毕业窗口、地点、语言、实习时长与工作许可。研究实习的博士条件只适用于对应职位。详情见 [JD_EVIDENCE.md](docs/JD_EVIDENCE.md)，来源核查记录见 [EVIDENCE_STATUS.json](docs/EVIDENCE_STATUS.json)。

## 本机运行与验证

使用 **Node.js 22 或更新版本**，无需安装第三方依赖。

```sh
npm run dev             # 本地预览，默认 http://127.0.0.1:4173
npm test                # 数据、所有路径变体、文档生成和真实浏览器交互检查
npm run build:docs      # 同步岗位、分层知识网络、JD 文档
npm run check:sources   # 单独联网复核官方来源与短摘
```

网页使用原生 HTML / CSS / JavaScript。`sphere.js` 保存三维坐标并投影为 SVG，让小规模分层球体中的节点同时支持键盘和屏幕阅读器，无需外部图形库。

浏览器检查默认使用 Windows 的 Microsoft Edge，可通过 `EDGE_BIN` 指定其他 Chromium。检查使用独立临时配置；截图默认写入临时预览目录，可通过 `ATLAS_SCREENSHOT_DIR` 指定位置。

## 项目文件

| 路径 | 用途 |
|---|---|
| `index.html` / `styles.css` | 页面结构、深色界面、响应式布局与焦点反馈 |
| `app.js` | 岗位、层级导航、清单、学习路径、搜索和进度 |
| `sphere.js` | 三维投影、旋转、缩放、节点激活与动态偏好 |
| `data.js` | 六个方向、概念与模块、技能依赖、招聘证据 |
| `docs/ROLE_REQUIREMENTS.md` | 自动生成的岗位拆解和学习顺序 |
| `docs/SKILL_NETWORK.md` | 自动生成的层级索引、345 项学习内容与依赖表 |
| `docs/KNOWLEDGE_ARCHITECTURE.md` | 层级、关系语义与维护方法 |
| `docs/JD_EVIDENCE.md` | 自动生成的逐职位资格、技能和证据 |
| `scripts/validate-data.cjs` | 引用、归属、循环和全部路径变体校验 |
| `scripts/browser-smoke.cjs` | 真实浏览器交互、球体动态及多尺寸检查 |
| `scripts/check-jd-sources.cjs` | 官方来源与原文短摘核查 |

GitHub Pages 从 `main` 分支根目录发布。修改 `data.js` 后运行验证，生成文档由脚本同步。后续可逐技能补充资源、练习与个人成果，不必把整张地图同时学完。
