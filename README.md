# Career Skill Atlas · 计算机实习知识地图

一张面向个人学习与实习准备的交互式知识地图。它把常见计算机实习岗位拆成实习生交付、核心与可选能力、作品证据和面试信号，并用前置关系连接成知识网络。

## 在本机运行

需要 Node.js 18 或更新版本，不需要安装第三方依赖。

启动：**npm run dev**

打开终端提示的本地地址，默认是 http://127.0.0.1:4173。

运行数据校验：**npm test**。它会检查岗位引用的技能、技能前置项、岗位来源及前置关系环路。

也可以在 GitHub 仓库设置中启用 GitHub Pages，把来源选为 main 分支根目录；发布后就是静态站点。

## 交互功能

- 按软件与系统、数据与 AI、云与基础设施、安全与终端筛选岗位。
- 搜索岗位、技能和相关关键词。
- 选择岗位查看典型实习任务、常见核心技能、任选其一的语言或平台、进阶项、作品证据和面试关注点。
- 知识网络使用颜色区分层级，箭头表示“前置知识 → 后续技能”；选择岗位会显示相关技能及它们的前置依赖。
- 点击节点查看解释、学习理由、前置项、验证成果和关联岗位。
- 通过分层和搜索浏览技能卡片；网络支持滚轮缩放与拖动平移。
- 在节点详情中记录“未开始、学习中、可以讲清、实现并验证”；状态只保存在当前浏览器，可筛选尚未开始的知识点。

## 知识模型

数据单独维护在 data.js。技能节点包含：

- layer：工具与基础、工程与系统、数据与 AI、岗位分支。
- prerequisites：必须先理解或实践的知识节点。
- summary、why、proof：知识边界、学习价值和验证出口。
- roleIds：哪些岗位会复用这项技能。

岗位画像包含常见实习工作、核心要求、任选其一的语言/平台、加分能力、简历作品证据、面试信号和参考链接。这里把具体语言作为可替换路径，避免把某个语言误写成所有团队的共同硬门槛。

## 岗位与招聘信息口径

目前覆盖 17 类岗位画像：后端、前端、全栈、C++/系统、移动端、测试开发、数据工程、数据分析、机器学习工程、算法/机器学习算法、AI 应用/Agent、云平台/DevOps/SRE、AI 基础设施/GPU、网络安全、嵌入式/IoT、量化开发和量化研究。

岗位画像是对常见职责与能力结构的归纳，不是实时职位库，也不是对公司招聘要求的逐条引用。每个岗位的“常见核心能力”表示通用准备框架，不代表所有公司均设置相同硬门槛；“任选其一”表示存在不同技术栈路径；“加分/进阶能力”不是投递必备项。实习资格经常取决于在校状态、毕业时间、专业、连续实习周期、每周到岗天数、地点与批次。投递时请逐条核对具体 JD。

外部引用按用途区分为职业分类/趋势资料、公司招聘入口和技术学习参考。公司链接是招聘搜索入口，不是已核实的具体职位条目；应按目标地区和批次检索当年岗位，并再次核对毕业资格、工作地点、实习周期、技术栈和项目职责。不能把职业趋势数据或通用能力框架当作当前招聘门槛的证据。

## 文件结构

index.html：单页结构

styles.css：深色响应式界面

app.js：搜索、筛选、岗位面板和知识网络交互

data.js：岗位、技能、关系和参考链接（当前 17 个岗位、77 个技能节点）

design-system/career-skill-atlas/：UI 设计规范

scripts/serve.cjs：无依赖本地静态服务器

scripts/validate-data.cjs：知识图数据校验

scripts/browser-smoke.cjs：浏览器交互与窄屏检查

## 后续扩展建议

1. 为具体招聘批次添加岗位记录：公司、招聘链接、地点、毕业年限、投递截止日、实习周期、证据摘录和核查日期。
2. 将个人掌握度状态扩展为阶段里程碑、复习日期和项目证据链接。
3. 为主修方向添加更细的课程、练习、项目里程碑和面试题索引。
4. 如果维护公司招聘数据，保留原始链接与日期，并把已过期职位和长期通用能力分开。

## 设计

产品整体使用低装饰的深色技术知识台风格，布局兼顾岗位阅读和技能关系浏览；支持窄屏、键盘焦点和减少动态效果设置。完整界面规范见 design-system/career-skill-atlas/MASTER.md。
