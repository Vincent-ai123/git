01 / ROLE EXPLORER

先从岗位倒推学习顺序

岗位不是课程清单。先看实习生会交付什么，再决定哪些知识必须深入，哪些知识只需要建立工作理解。

i先核对资格，再准备技术。 实习招聘常把在校状态、毕业年份、连续实习周期、每周到岗天数、工作地点和专业方向列为硬条件；这些信息随公司、团队和招聘批次变化，必须以具体 JD 为准。
SELECTION / ALL ROLES

选择一个岗位

点击岗位卡片，查看实习生常见交付、必备技能、作品证据和面试信号。也可以直接在知识网络中点击一个节点。

建议先选一个你愿意投入 8—12 周验证的方向。

02 / KNOWLEDGE NETWORK

看见技能之间的依赖关系

箭头：前置知识 → 后续技能。岗位直接关联节点为实线边框，路径基础和补齐的前置项为虚线边框；✓ 表示已实现并验证。图谱支持键盘选择，关系清单逐项列出相同节点与前置项。

03 / SKILL LIBRARY

知识节点的最小解释单元

每个节点都给出学习目的、前置关系、练习出口和岗位关联。它们是你以后逐项追问“去哪学、怎么学”的索引。

进度保存在当前浏览器；导出文件可迁移到其他设备。

04 / LEARNING PATH

为目标岗位排列一条学习路径

先选主修方向和一条技术栈，再沿先修基础、岗位核心、项目验证和进阶方向推进。路径是可调整的准备建议，节点勾选不等于录用评估。

05 / JD EVIDENCE

把能力模型对照招聘原文

官方样例保留资格、明示技能、加分项、原文短摘与核查日期。样本主要来自海外与香港招聘，包含研究岗位和方向汇总，用于理解差异，不能推算中国岗位热度或统一门槛。

REFERENCE NOTES
