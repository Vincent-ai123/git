04 / LEARNING PATH

一条能产出证据的主线

先完成共同底座和一个完整作品，再把时间投向一个岗位分支。每一段都应该留下可以展示、复现和解释的结果。

01
TOOLCHAIN

工具层

Shell、Git、CMake、测试、调试。目标是从干净目录稳定构建并定位问题。

出口：可复现仓库
02
CORE ENGINEERING

通用工程层

现代 C++ / Python、算法、Linux、并发、网络、SQL。目标是能解释机制并写出边界测试。

出口：可测试模块
03
PROOF PROJECT

作品验证层

用行情回放与订单簿或同等复杂度项目，把数据、系统、测试和性能连起来。

出口：可讲述作品
04
SPECIALIZE

岗位分支层

从 Agent、AI 系统 / GPU、量化研究、数据工程等方向中选择主修，按 JD 继续加深。

出口：岗位匹配证据

REFERENCE NOTES

如何使用这张地图

岗位画像用于建立准备框架，不替代目标公司的招聘公告。先用岗位卡片确定技能边界，再用知识网络找前置关系，最后为每个节点安排练习和可验证成果。外链是职业分类、学习资料和招聘搜索入口，不是当前招聘需求的逐条引用；资格以目标职位原文为准。
